> **💡 はじめに：** このガイドは、Surface Pro 6（i5-8350U / 8GB / 256GB）の実機検証に基づいている。この最適化セットを完了させた後、Cドライブの空き容量が **85GBから114GBへ跳ね上がり**（なんと **29GB** も絞り出した）、システム全体の動作が明らかに滑らかになった。
> **⚠️ 免責事項：** システムの深部を弄ることになるので、万が一に備えて作業前に**システムの復元ポイント**を作成しておくことを強くおすすめする。

## 1. パフォーマンスとCPUの最適化

### 1.1 VBS（コア分離）の無効化

VBSはかなりのCPUリソースを食う。これをオフにするだけで10〜15%のパフォーマンス向上が見込める。

* **GUIでの操作**：`設定` -> `プライバシーとセキュリティ` -> `Windows セキュリティ` -> `デバイス セキュリティ` -> `コア分離の詳細` -> **メモリ整合性** をオフにする。
* **コマンドライン方式**：

```powershell
bcdedit /set hypervisorlaunchtype off
```

* *※再起動後に有効になる。*

### 1.2 Windows Defenderの調教

無理やり削除して謎のシステムエラーを引き起こすより、ホワイトリストやポリシーを使って「盲目」にしてやる方が賢い。

* **プロセスのホワイトリスト化**：
Windowsセキュリティの除外設定に `explorer.exe` と `SearchIndexer.exe` を追加する。これだけで無駄な日常的リソース消費をかなり抑えられる。
* **リアルタイム保護の無効化**（先にUIから **改ざん防止** をオフにしておく必要がある）：

```powershell
Set-MpPreference -DisableRealtimeMonitoring $true
Set-MpPreference -DisableBehaviorMonitoring $true
Set-MpPreference -DisableIOAVProtection $true
Set-MpPreference -DisablePrivacyMode $true
Set-MpPreference -SignatureDisableUpdateOnStartupWithoutEngine $true
Set-MpPreference -DisableArchiveScanning $true
Set-MpPreference -DisableIntrusionPreventionSystem $true
Set-MpPreference -DisableScriptScanning $true
```

* **タスクスケジューラの最適化**：
`タスク スケジューラ` を開き、`Microsoft\Windows\Windows Defender` に移動し、`Windows Defender Scheduled Scan` の「条件」タブにあるトリガーを無効化する。

### 1.3 保護履歴のクリア（神経質なオタク向け）

タスクバーのセキュリティセンターに居座る頑固な黄色いビックリマークを消し去るための手順：

1. **権限の取得**：`C:\ProgramData\Microsoft\Windows Defender\Scans\History\Service` フォルダを右クリックし、管理者として所有権を取得する；
2. **直接削除**：その中にある `DetectionHistory` フォルダを削除する；
3. *※「アクセスが拒否されました」と出たら、**セーフモード**で起動して操作すればOKだ。*

## 2. ストレージ空間のサルベージ（29GBを絞り出す秘密）

### 2.1 LZX圧縮の有効化

Windowsに隠された透過圧縮機能を利用する。日常的なパフォーマンスにはほとんど影響しない。

* **システム全体のCompact OS圧縮**：

```powershell
compact /compactos:always
```

* **大型アプリ/ゲーム向けの個別LZX圧縮**：

```powershell
compact /c /s /a /i /exe:lzx "C:\Program Files\YourApp\*"
```

### 2.2 冗長な予約済みスペースとキャッシュの削減

* **休止状態と高速スタートアップの無効化**（これだけで数GB節約）：

```powershell
powercfg -h off
```

* **予約済みストレージの無効化**（約7GBの節約）：

```powershell
DISM.exe /Online /Set-ReservedStorageState /State:Disabled
```

### 2.3 古いドライバと更新バックアップのクリーンアップ

最も即効性のある容量回復方法の一つ（注意：クリーンアップ後は以前のシステム更新をアンインストールできなくなる）：

```powershell
Dism /Online /Cleanup-Image /StartComponentCleanup /ResetBase
```

### 2.4 仮想メモリ（PageFile）の最適化

8GBメモリのPC向け。Cドライブの空き容量が「システム管理サイズ」によって乱高下するのを防ぐ。

* **固定サイズの設定を推奨**：初期サイズ：`4096MB`、最大サイズ：`8192MB`。
