### 作成したリポジトリを修正する

通常、テンプレートの作者が便利なツールや説明書を用意してくれている。以下はChirpyテンプレートを例にした、Chirpy公式ドキュメントからの引用だ：

#### サイトの作成

GitHubにログインして [ChirpyをFork](https://github.com/cotes2020/jekyll-theme-chirpy/fork) し、`USERNAME.github.io` （`USERNAME`は君のGitHubユーザー名）にリネームする。

リポジトリをローカルPCにcloneし、PCにNode.jsが入っていることを確認してから、リポジトリのルートディレクトリでこのコマンドを走らせる：

$ bash tools/init.sh

このコマンドは以下の作業を代行してくれる：コードを最新の安定版Releaseタグに切り替える（開発ブランチの不安定なコードを回避）、不要なサンプルファイルのクリーンアップ、CSS/JSリソースのビルド、そして変更のコミットだ。

#### 基本設定

必要に応じて `_config.yml`{: .filepath } 内の変数を修正する。よく使うのは `url`、`avatar`、`timezone`、`lang` あたり。

##### ソーシャルコンタクト

サイドバー下部のソーシャルアイコンは、`_data/contact.yml`{: .filepath } で必要に応じてオンオフできる。

##### カスタムスタイル

スタイルを変更したい場合は、テーマ内の `assets/css/jekyll-theme-chirpy.scss`{: .filepath } を自分のサイトの同じパスにコピーし、末尾にカスタムCSSを追記すればOK。

バージョン6.2.0以降、`_sass/addon/variables.scss`{: .filepath } のSASS変数を上書きしたい場合は、`_sass/main.scss`{: .filepath } をサイトソースの `_sass`{: .filepath } ディレクトリにコピーし、新しく `_sass/variables-hook.scss`{: .filepath } を作成して新しい値を書き込めばいい。

#### 手動ビルドとデプロイ

自前サーバーを使っていてGitHub Actionsでの自動ビルドが使えない場合は、ローカルでビルドしてから生成されたファイルをサーバーに放り込む必要がある。

GitHubリポジトリでウェブページをGitHub Pagesとして設定する。リポジトリのSettingsページを開き、GitHub Pagesセクションで Enforce HTTPS と Custom domain にチェックを入れ、カスタムドメインを入力してSaveを押す。こんな感じ：
