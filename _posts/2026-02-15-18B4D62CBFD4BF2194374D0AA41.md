> **💡 前言：** 本指南基于 Surface Pro 6（i5-8350U / 8GB / 256GB）实机测试。做完这套优化后，C 盘可用空间从 **85GB 飙升到 114GB**（狂挤出 **29GB**），整机操作明显顺滑多了。
> **⚠️ 免责声明：** 涉及系统深层修改，动手前强烈建议先建一个**系统还原点**以备不时之需。

## 1. 性能与 CPU 优化

### 1.1 关闭 VBS（核心隔离）

VBS 会吃掉不少 CPU 算力，关掉能带来 10~15% 的性能提升。

* **图形界面**：`设置` -> `隐私和安全性` -> `Windows 安全中心` -> `设备安全性` -> `核心隔离详细信息` -> 关闭 **内存完整性**。
* **命令行方式**：

```powershell
bcdedit /set hypervisorlaunchtype off
```

* *需要重启生效。*

### 1.2 调教 Windows Defender

与其暴力强删导致系统玄学报错，不如用白名单和策略把它“致盲”。

* **进程白名单**：
在 Windows 安全中心的排除项里加上 `explorer.exe` 和 `SearchIndexer.exe`，能省下不少无谓的日常开销。
* **关闭实时保护**（需要先在界面关掉 **篡改防护**）：

```powershell
Set-MpPreference -DisableRealtimeMonitoring $true
Set-MpPreference -DisableBehaviorMonitoring $true
Set-MpPreference -DisableIOAVProtection $true
Set-MpPreference -DisablePrivacyMode $true
Set-MpPreference -SignatureDisableUpdateOnStartupWithoutEngine $true
Set-MpPreference -DisableArchiveScanning $true
Set-MpPreference -DisableIntrusionPreventionSystem $true
Set-MpPreference -DisableScriptScanning $true
```

* **优化计划任务**：
打开 `任务计划程序` -> 定位到 `Microsoft\Windows\Windows Defender`，把 `Windows Defender Scheduled Scan` 下“条件”里的触发项禁用掉。

### 1.3 清空保护历史记录（强迫症专享）

用来干掉任务栏安全中心顽固的黄色感叹号：

1. **获取权限**：对 `C:\ProgramData\Microsoft\Windows Defender\Scans\History\Service` 文件夹右键取得管理员所有权；
2. **直接删除**：删掉里面的 `DetectionHistory` 文件夹；
3. *如果提示拒绝访问，进**安全模式**操作即可。*

## 2. 抢救存储空间（狂榨 29GB 的秘密）

### 2.1 开启 LZX 压缩

利用 Windows 隐藏的透明压缩，几乎不影响日常性能。

* **系统全局 Compact OS 压缩**：

```powershell
compact /compactos:always
```

* **针对大型应用/游戏手动 LZX 压缩**：

```powershell
compact /c /s /a /i /exe:lzx "C:\Program Files\YourApp\*"
```

### 2.2 砍掉冗余的预留空间与缓存

* **关闭休眠与快速启动**（立省好几个 G）：

```powershell
powercfg -h off
```

* **禁用保留存储**（立省约 7GB）：

```powershell
DISM.exe /Online /Set-ReservedStorageState /State:Disabled
```

### 2.3 清理老旧驱动与更新备份

最立竿见影的回血方式之一（注意：清理后之前的系统更新就无法卸载了）：

```powershell
Dism /Online /Cleanup-Image /StartComponentCleanup /ResetBase
```

### 2.4 虚拟内存（PageFile）优化

针对 8GB 内存机器，避免因为“系统托管”导致 C 盘剩余空间忽大忽小。

* **建议设置固定大小**：初始大小：`4096MB`，最大值：`8192MB`。
