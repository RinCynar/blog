> **💡 前言：** 本指南基于 Surface Pro 6（i5-8350U / 8GB / 256GB）实机测试总结。完成整套优化后，C 盘可用空间从 **85GB 提升至 114GB**（净赚 **29GB**），系统响应流畅度显著提升。
> **⚠️ 免责声明：** 涉及系统底层深度调优，操作前强烈建议创建**系统还原点**以备不时之需。

## 1. 性能释放与 CPU 调优

### 1.1 禁用 VBS（基于虚拟化的安全性 / 核心隔离）

VBS 会占用相当可观的 CPU 算力开销。将其关闭可带来 10%~15% 的性能回血。

* **图形界面**：`设置` -> `隐私和安全性` -> `Windows 安全中心` -> `设备安全性` -> `核心隔离详细信息` -> 关闭 **内存完整性**。
* **命令行方式**：

```powershell
bcdedit /set hypervisorlaunchtype off
```

* *需重启系统生效。*

### 1.2 Windows Defender 精细化降噪

与其粗暴剔除导致玄学故障，不如通过白名单与策略调优将其“致盲”，卸下系统包袱。

* **进程白名单**：
在 Windows 安全中心排除项中添加 `explorer.exe` 与 `SearchIndexer.exe`，大幅降低日常 I/O 占用与资源抖动。
* **禁用实时防护**（需先在界面关闭 **篡改防护**）：

```powershell
Set-MpPreference -DisableRealtimeMonitoring $true
Set-MpPreference -DisableBehaviorMonitoring $true
Set-MpPreference -DisableIOAVProtection $true
Set-MpPreference -DisablePrivacyMode $true
Set-MpPreference -SignatureDisableUpdateOnStartupWithoutEngine $true
Set-MpPreference -DisableArchiveScanning $true
Set-MpPreference -DisableIntrusionPreventionSystem $true
Set-MpPreference -DisableScriptScanning $true
```

* **优化计划任务**：
打开 `任务计划程序` -> 定位至 `Microsoft\Windows\Windows Defender`，将 `Windows Defender Scheduled Scan` 下“条件”选项卡内的唤醒触发项关闭。

### 1.3 清空防护历史记录（强迫症福音）

用于根治任务栏安全中心顽固的黄色惊叹号：

1. **夺取权限**：为 `C:\ProgramData\Microsoft\Windows Defender\Scans\History\Service` 文件夹获取管理员所有权；
2. **物理删除**：直接清空该路径下的 `DetectionHistory` 文件夹；
3. *若提示权限拒绝，进入**安全模式**执行即可。*

## 2. 存储空间回收（白嫖 29GB 的秘诀）

### 2.1 开启 LZX 透明算法压缩

调用 Windows 内置的无损透明压缩机制，兼顾读取性能与体积收缩。

* **系统全局 Compact OS 压缩**：

```powershell
compact /compactos:always
```

* **针对大型应用/游戏手动 LZX 压缩**：

```powershell
compact /c /s /a /i /exe:lzx "C:\Program Files\YourApp\*"
```

### 2.2 剔除冗余预留与休眠缓存

* **关闭休眠与快速启动**（直接释放数 GB 空间）：

```powershell
powercfg -h off
```

* **禁用 Windows 预留存储**（立省约 7GB 空间）：

```powershell
DISM.exe /Online /Set-ReservedStorageState /State:Disabled
```

### 2.3 清理陈旧驱动与更新备份

深度释放 C 盘的最强手段（注意：执行后将无法回滚过往系统补丁）：

```powershell
Dism /Online /Cleanup-Image /StartComponentCleanup /ResetBase
```

### 2.4 虚拟内存（Pagefile）锁容优化

针对 8GB 内存设备，避免因“系统自动管理”导致 C 盘可用空间剧烈忽大忽小。

* **调优建议**：设定固定静态区间。初始大小：`4096MB`，最大值：`8192MB`。
