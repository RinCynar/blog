### 第二步：配置并初始化仓库

通常模板作者都会提供配套工具和说明文档。以下以 Chirpy 模板为例进行说明。
以下内容引自 Chirpy 官方文档：

#### 创建你的网站

登录 GitHub [Fork Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy/fork)，随后重命名为 `USERNAME.github.io`（`USERNAME` 为你的用户名）。

接着将仓库克隆到本地机器，确保已安装 Node.js，进入仓库根目录执行如下命令：

$ bash tools/init.sh

上述命令将：
1. 检出至最新 Release 标签代码（确保站点稳定，避开主分支的开发中代码）；
2. 清理非必要的示例文件，并重构 GitHub 相关配置；
3. 构建 CSS/JS 静态资源并交由 Git 跟踪；
4. 自动生成新提交保存上述变更。

#### 基础配置

根据需要修改 `_config.yml`{: .filepath } 中的变量。典型配置项包括：`url`、`avatar`、`timezone`、`lang` 等。

##### 社交链接配置

社交链接展示在侧边栏底部。可在 `_data/contact.yml`{: .filepath } 中自由开启或关闭指定联系方式。

##### 自定义样式

如需自定义样式，可将主题中的 `assets/css/jekyll-theme-chirpy.scss`{: .filepath } 拷贝至站点的对应路径，并在末尾追加你的自定义样式。

自 `6.2.0` 版本起，若要覆盖 `_sass/addon/variables.scss`{: .filepath } 中定义的 SASS 变量，需将 `_sass/main.scss`{: .filepath } 复制到源码的 `_sass`{: .filepath } 目录，再新建 `_sass/variables-hook.scss`{: .filepath } 赋予新值。

#### 手动构建与部署

若使用自建服务器，无法直接享受 GitHub Actions 的自动构建便利，需在本地机器完成构建后将静态文件上传至服务器。
