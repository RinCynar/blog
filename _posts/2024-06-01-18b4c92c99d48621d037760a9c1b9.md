### 修改刚刚创建的仓库

通常模板作者都会给好工具和说明。下面以 Chirpy 模板为例，以下内容来自 Chirpy 官方文档：

#### 创建你的网站

登录 GitHub [Fork Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy/fork)，重命名为 `USERNAME.github.io`（`USERNAME` 换成你的 GitHub 用户名）。

把仓库 clone 到本地电脑，确保电脑装了 Node.js，然后进入仓库根目录跑一下这条命令：

$ bash tools/init.sh

这条命令会帮你：把代码切到最新的稳定 Release 标签（避开开发分支的不稳定代码）、清理多余的示例文件、构建 CSS/JS 资源并提交保存。

#### 基本配置

按需修改 `_config.yml`{: .filepath } 里的变量。常见的有：`url`、`avatar`、`timezone`、`lang` 等。

##### 社交联系方式

侧边栏底部的社交图标，可以在 `_data/contact.yml`{: .filepath } 里按需开启或关闭。

##### 自定义样式

如果想改样式，把主题里的 `assets/css/jekyll-theme-chirpy.scss`{: .filepath } 拷到自己站点的相同路径下，在末尾加上自定义 CSS 即可。

从 6.2.0 版本起，如果要覆盖 `_sass/addon/variables.scss`{: .filepath } 里的 SASS 变量，把 `_sass/main.scss`{: .filepath } 复制到站点源码的 `_sass`{: .filepath } 目录，再新建一个 `_sass/variables-hook.scss`{: .filepath } 写上新值就行。

#### 手动构建与部署

如果用自建服务器，没法直接用 GitHub Actions 自动构建，就需要在本地构建好再把生成的文件丢到服务器上。

在 GitHub 仓库里把网页设置为 GitHub Pages。打开仓库的 Settings 页面，在 GitHub Pages 区域勾选 Enforce HTTPS 和 Custom domain，把你的自定义域名填进去，点 Save 保存。像这样：
