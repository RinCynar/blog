## RCS.aGmua Tool Usage Guide

## Updates are only released on [this website](https://aGmua.dpdns.org) and [GitHub](https://github.com/RinCynar/rcs.aGmua). Any other channels are unofficial distributions, please use your own judgment.

### Latest version: 1.91, [Download link](https://aGmua.dpdns.org), [GitHub Page](https://github.com/RinCynar/rcs.aGmua)

### Overview

#### The RCS tool is a neat little text encryption utility based on the RC4 encryption algorithm. You can use it to encrypt and decrypt text with custom keys, manage your keys, and keep a history of your encryption/decryption operations. The tool supports a range of commands for key management, checking for updates, or attempting brute-force decryption.

#### Features

##### Text Encryption/Decryption: Securely encrypt and decrypt text using the RC4 algorithm and custom keys.

##### Key Management: Easily add, delete, and view encryption keys.

##### History Management: Save and display a history of encrypted/decrypted messages.

##### Update Notifications: Automatically check for updates and alert you when a new version is available.

##### Configuration Reset: Reset the tool to its default config with one click.

##### Brute Force: Supports brute-force attempts with custom key lengths.

##### Simple and Easy to Use: Intuitive command design, very handy to use.

#### Environment Requirements

##### Python 3.x

##### arc4 module

##### requests module

### Installation

#### Make sure Python and the required dependencies are installed:

##### pip install arc4 requests

### Usage

#### Run the script to enter interactive mode:

##### python aGmua.py -i

#### Available Commands

##### relp: Display usage instructions.

##### rak <new-key>: Add a new encryption key.

##### rch: Clear the encryption/decryption history.

##### rck: View all currently saved keys.

##### rdk -<key_number>: Delete the key with the specified index.

##### rxit: Exit the tool.

##### rsh: View the encryption/decryption history.

##### rc <text>: Attempt brute-force decryption on the specified text.

##### res: Restore default configuration.

##### rcu: Check for updates.

### Function Descriptions

#### print_message(message)

##### Prints a message to the console, padded with newlines before and after.

#### get_input(prompt, default=None)

##### Prompts the user for input, returns the default value if no input is provided.

#### load_keys()

##### Loads saved keys from the key file.

#### save_keys()

##### Saves keys to the key file.

#### reset()

##### Resets the tool: deletes the key file and history, and restores the default key.

#### add_key(new_key)

##### Adds a new key if it doesn't already exist.

#### delete_key(key_number)

##### Deletes the specified key by its index (the default key cannot be deleted).

#### utf16_to_bytes(s)

##### Converts a UTF-16 string into bytes.

#### rc4_encrypt(key, plaintext)

##### Encrypts plaintext using the RC4 algorithm and the specified key.

#### rc4_decrypt(key, ciphertext)

##### Decrypts ciphertext using the RC4 algorithm and the specified key.

#### bytes_to_hex(b)

##### Converts bytes to a hex string.

#### hex_to_bytes(h)

##### Converts a hex string to bytes.

#### choose_key_for_encryption()

##### Lets the user choose a key from the existing ones for encryption.

#### choose_key_for_decryption()

##### Lists and returns available keys to attempt decryption.

#### save_history(record)

##### Writes a record to the history file.

#### display_history()

##### Prints the encryption/decryption history.

#### clear_history()

##### Clears the encryption/decryption history.

#### check_for_updates()

##### Requests the update URL to check for new versions.

#### handle_command(user_input)

##### Parses user commands and executes the corresponding operations.

#### interactive_mode()

##### Starts interactive mode to receive commands and encryption/decryption inputs.

#### print_help()

##### Prints help and usage instructions.

#### display_keys()

##### Prints the currently saved keys.

#### decrypt_text(user_input)

##### Decrypts text using a specified key or all available keys.

#### encrypt_text(plaintext)

##### Encrypts plaintext using the selected key and saves it to the history.

#### bruteforce_decrypt(ciphertext)

##### Iterates through keys of a specified length to brute-force the ciphertext.

### Usage Examples

#### Encrypt Text

##### Enter interactive mode:

###### python aGmua.py -i

##### Enter the text to encrypt:

###### # Hello, World!

##### Choose a key number, or just use the default key:

###### # Choose a key number (default is 0): 0

##### The ciphertext will be displayed immediately and automatically saved to the history.

#### Decrypt Text

##### Enter interactive mode:

###### python aGmua.py -i

##### Enter the ciphertext following this format (- <ciphertext>):

###### # - 5D41402ABC4B2A76B9719D911017C592

##### The tool will attempt to decrypt it using all available keys and display the results.

#### Add a New Key

##### Enter interactive mode:

###### python aGmua.py -i

##### Add the key:

##### # rak my-new-key

#### View History

##### Enter interactive mode:

###### python aGmua.py -i

##### Show encryption/decryption history:

###### # rsh

### Feature Highlights

#### Secure Text Encryption/Decryption

##### RCS.aGmua is based on the RC4 algorithm, securely handling text encryption and decryption. You can also configure multiple keys and swap them out for enhanced security.

#### Hassle-free Key Management

##### Key management is a breeze; you can add, delete, and view keys with just a few simple commands.

#### Complete History Tracking

##### All encrypted and decrypted messages are saved in a history file. You can view or clear it anytime, making it easy to look back at previously processed content.

#### Update Alerts

##### Automatically detects new versions and prompts you to update, ensuring you can grab new features and fixes as soon as possible.

#### One-Click Reset

##### Supports one-click restoration to the default config, super useful when you want a fresh start or messed up the configuration.

#### Brute Force

##### Comes with a built-in brute-force feature that supports testing against different key lengths. Handy for trying your luck when you occasionally forget a key.

#### Friendly Interaction

##### The command-line interface is intuitive and easy to grasp. You don't need complex background knowledge to easily get the hang of encrypting, decrypting, and managing keys.
