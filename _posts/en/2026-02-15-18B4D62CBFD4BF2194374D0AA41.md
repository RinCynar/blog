> **💡 Intro:** This guide is based on real-world testing on a Surface Pro 6 (i5-8350U / 8GB / 256GB). After doing this set of optimizations, the available space on the C drive skyrocketed from **85GB to 114GB** (squeezing out an insane **29GB**), and overall operations got noticeably smoother.
> **⚠️ Disclaimer:** This involves deep system modifications. It is highly recommended that you create a **system restore point** before getting your hands dirty, just in case.

## 1. Performance & CPU Optimization

### 1.1 Disable VBS (Core Isolation)

VBS eats up quite a bit of CPU power. Turning it off can bring a 10~15% performance boost.

* **GUI Method**: `Settings` -> `Privacy & security` -> `Windows Security` -> `Device security` -> `Core isolation details` -> Turn off **Memory integrity**.
* **Command Line Method**:

```powershell
bcdedit /set hypervisorlaunchtype off
```

* *Requires a reboot to take effect.*

### 1.2 Taming Windows Defender

Instead of violently forcefully deleting it and causing weird system errors, it's better to "blind" it with whitelists and policies.

* **Process Whitelisting**:
Add `explorer.exe` and `SearchIndexer.exe` to the exclusions in Windows Security. This saves a lot of meaningless daily overhead.
* **Disable Real-time Protection** (Requires turning off **Tamper Protection** in the UI first):

```powershell
Set-MpPreference -DisableRealtimeMonitoring $true
Set-MpPreference -DisableBehaviorMonitoring $true
Set-MpPreference -DisableIOAVProtection $true
Set-MpPreference -DisablePrivacyMode $true
Set-MpPreference -SignatureDisableUpdateOnStartupWithoutEngine $true
Set-MpPreference -DisableArchiveScanning $true
Set-MpPreference -DisableIntrusionPreventionSystem $true
Set-MpPreference -DisableScriptScanning $true
```

* **Optimize Scheduled Tasks**:
Open `Task Scheduler` -> Navigate to `Microsoft\Windows\Windows Defender`, and disable the triggers under "Conditions" for `Windows Defender Scheduled Scan`.

### 1.3 Clear Protection History (For the OCD among us)

Used to wipe out that stubborn yellow exclamation mark in the taskbar security center:

1. **Get Permissions**: Right-click on the `C:\ProgramData\Microsoft\Windows Defender\Scans\History\Service` folder and take ownership as administrator;
2. **Direct Delete**: Delete the `DetectionHistory` folder inside;
3. *If it prompts Access Denied, just boot into **Safe Mode** to do it.*

## 2. Salvaging Storage Space (The secret to squeezing out 29GB)

### 2.1 Enable LZX Compression

Take advantage of Windows' hidden transparent compression, which barely impacts daily performance.

* **System-wide Compact OS Compression**:

```powershell
compact /compactos:always
```

* **Manual LZX Compression for Large Apps/Games**:

```powershell
compact /c /s /a /i /exe:lzx "C:\Program Files\YourApp\*"
```

### 2.2 Cut Redundant Reserved Space & Cache

* **Disable Hibernation & Fast Startup** (Saves several GBs instantly):

```powershell
powercfg -h off
```

* **Disable Reserved Storage** (Saves about 7GB instantly):

```powershell
DISM.exe /Online /Set-ReservedStorageState /State:Disabled
```

### 2.3 Clean Up Old Drivers & Update Backups

One of the most immediate ways to regain space (Note: after cleaning, previous system updates cannot be uninstalled):

```powershell
Dism /Online /Cleanup-Image /StartComponentCleanup /ResetBase
```

### 2.4 Virtual Memory (PageFile) Optimization

For 8GB RAM machines, avoid having the C drive's free space fluctuate wildly due to "System managed size".

* **Recommended fixed size**: Initial size: `4096MB`, Maximum size: `8192MB`.
