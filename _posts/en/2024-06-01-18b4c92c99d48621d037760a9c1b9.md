### Modify the newly created repository

Usually, template authors provide good tools and instructions. Taking the Chirpy template as an example, the following content is from the official Chirpy documentation:

#### Create your website

Log into GitHub, [Fork Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy/fork), and rename it to `USERNAME.github.io` (replace `USERNAME` with your GitHub username).

Clone the repository to your local machine, make sure you have Node.js installed, then enter the repo's root directory and run this command:

$ bash tools/init.sh

This command will help you: switch the code to the latest stable Release tag (avoiding unstable code from the dev branch), clean up redundant demo files, build CSS/JS assets, and commit the changes.

#### Basic Configuration

Modify the variables in `_config.yml`{: .filepath } as needed. Common ones include: `url`, `avatar`, `timezone`, `lang`, etc.

##### Social Contacts

The social icons at the bottom of the sidebar can be toggled on or off in `_data/contact.yml`{: .filepath } as needed.

##### Custom Styles

If you want to tweak styles, copy `assets/css/jekyll-theme-chirpy.scss`{: .filepath } from the theme into the exact same path of your site source, and append your custom CSS at the end.

From version 6.2.0 onwards, to override SASS variables in `_sass/addon/variables.scss`{: .filepath }, copy `_sass/main.scss`{: .filepath } to the `_sass`{: .filepath } directory in your site's source, then create a new `_sass/variables-hook.scss`{: .filepath } to write your new values.

#### Manual Build and Deployment

If you're using a self-hosted server and can't use GitHub Actions for automatic builds, you'll need to build it locally and toss the generated files onto your server.

### Set up your GitHub repository

Set the webpage to GitHub Pages within your GitHub repo. Open the repository's Settings page, check Enforce HTTPS and Custom domain in the GitHub Pages section, enter your custom domain, and hit Save. Like this:
<img src="/assets/img/image/image@20240601bywff01.png" alt="Examp1e" />
